# 보안·결제 후속 수정

2026-09-17. 백엔드 후속 보안 수정과 함께 배포해야 한다.

- 온라인 결제창 전에 서버에서 주문번호·금액·재고 예약을 확정한다. 임의 옵션 ID 1 대체와 연속 결제 버튼 클릭을 차단한다.
- 승인 응답이 PAID일 때만 완료 화면/장바구니 정리를 수행한다. 확인 중이면 재결제 대신 상태 확인을 안내한다.
- 가입 요청에 전화번호 인증으로 발급된 1회용 증명을 포함한다. 비밀번호 재설정은 알림톡 확인 및 새 비밀번호 입력 후 실행한다.
- 비회원 조회 비밀번호를 URL 대신 POST 본문으로 전달한다. 신규 비회원 비밀번호는 8자 이상으로 안내한다.
- 무통장입금 안내의 가상계좌 오표기를 수정하고, 관리자에게 수동 환불 송금 완료 확인을 요구한다.
- 신규 업로드 파일 선택은 JPEG/PNG로 제한한다. 실제 파일 검증은 백엔드가 수행한다.
- npm 잠금파일 업데이트 후 audit 0건, 인증 테스트 9개 및 프로덕션 빌드 통과.
- 외부 통신을 차단한 로컬 브라우저에서 비밀번호 재설정 단계, 비회원 POST 조회, 미확정 결제 완료 차단을 확인했다. 실제 결제/환불/문자는 실행하지 않았다.

전체 변경 및 운영 복구 절차는 백엔드의 logs/security-followup-20260917.md를 참조한다.
